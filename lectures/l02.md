### Bài Tập 01

Viết chương trình nhập giá tị cho hai số thực a, b. Tính giá trị biểu thức sau:

$$
\frac{\sqrt{a} - \sqrt{b}}{\sqrt[4]{a} - \sqrt[4]{b}} - \frac{\sqrt{a} + \sqrt[4]{ab}}{\sqrt[4]{a} + \sqrt[4]{b}}
$$

```python
a = float(input())
b = float(input())

result = (a**0.5 - b**0.5) / (a**0.25 - b**0.25) - (a**0.5 + (a*b)**0.25) / (a**0.25 + b**0.25)
```
